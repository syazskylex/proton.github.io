# ProtonKV

ProtonKV is a responsive website for Proton Atiara Johan 4S Puchong. It introduces the Proton vehicle range and gives visitors ways to explore models, view brochures, arrange a test drive, and contact the showroom.

## What you'll find

- A full-screen hero with links to the model lineup and test-drive booking
- An overview of Proton ownership benefits, including warranty, technology, awards, and after-sales service
- Nine model listings, grouped into sedans, a hatchback, SUVs, and electric vehicles:
  - **Sedans:** Saga, Persona, S70
  - **Hatchback:** Iriz
  - **SUVs:** X50, X70, X90
  - **Electric:** e.MAS 7, e.MAS 5
- Model details and downloadable brochures
- Showroom contact information, a contact form, map, and photo gallery

## Run locally

This is a static site; no build step or package installation is required. From the project directory, start a local web server:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). The page loads some libraries and media from external CDNs, so an internet connection is needed for all content and styling to appear.

## Project files

- `index.html` — page content and layout
- `web.css` — shared site styles
- `web.js` — shared interactive behavior
- `assets/` — vehicle images, brochures, and other local media
